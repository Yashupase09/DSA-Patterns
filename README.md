# 📘 DSA Patterns Wise Questions & Solutions

## 👩‍🎓 About This Project
I am a student, and I created this repository to organize my practice of **Data Structures & Algorithms (DSA)**. Instead of solving random problems, I grouped questions **pattern‑wise** so that learning becomes systematic and easier to follow.

## 🎯 Purpose
- Build strong **problem‑solving skills** by recognizing common patterns.  
- Make **interview preparation** more structured.  
- Share a **reference repo** that can help other students learning DSA.  

## 📂 Repository Structure
Each folder represents a **pattern** and contains:
- Problem statement  
- Explanation of the approach  
- Code solution (with comments)
